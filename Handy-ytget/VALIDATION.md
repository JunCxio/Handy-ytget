# 验证记录

版本：0.3.1。验证日期：2026-10-26。环境：Windows x64、Rust 1.99.1、GNU 工具链、Microsoft Edge WebView2。验证使用随包的 yt-dlp、Deno、FFmpeg 和 FFprobe。

0.3.1 仅修改软件名称和发布文件名；以下下载及组件功能验证沿用 0.3.0 和标注的历史版本记录。

## 已通过

- 0.3.1 改名验证：界面、窗口标题、Windows 产品名称、程序及发布包名称统一为 `Handy-ytget`；程序版本为 0.3.1，保留原应用标识与配置路径。10 项单元测试通过，Clippy 无警告，前端功能及多尺寸布局检查通过。正式程序可启动和正常关闭，无调试监听端口。

- 共享命令行工程：4 项单元测试，覆盖链接校验、参数构造和命令行输入；Clippy 无警告。
- 桌面工程：10 项单元测试，覆盖进度解析、元数据筛选、直播拒绝、画质和封装校验、五种下载模式的参数契约、字幕语言及来源、最终字幕路径与缺失字幕拒绝、版本比较、校验和选择及异常压缩包；Clippy 无警告，Rust 格式检查通过。
- 前端：JavaScript 语法检查；浏览器自动化验证默认“视频＋字幕”、五种模式、语言及人工／自动字幕选择、无字幕提示和下载禁用、视频及音频暂停继续、暂停时参数锁定、转换时不能暂停，以及取消、错误、目录选择、检查更新和失败重试。
- 布局：使用长中文目录，验证 1120、860、746、573、375 像素宽度下无横向溢出；画质、封装格式和“选择目录”按钮均可见；下拉箭头距右边框 12 像素。
- 组件首装（0.2.1 已实测，本轮复用组件管理逻辑与现有组件）：在独立测试应用标识下，不提供捆绑组件且 PATH 中没有下载工具，真实下载、校验并一次安装 yt-dlp、Deno、FFmpeg 和 FFprobe。四个可执行文件的 SHA256 均与已核验的发行文件一致，安装临时目录已清理。
- 组件更新（0.2.1 已实测）：真实查询官方最新版本，将测试缓存中的 yt-dlp 替换为旧版本号测试程序后，正确识别并下载更新；更新后的 SHA256 与官方发行文件一致，无需更新的其他组件未变化。重启后直接复用缓存，无需再次下载。
- 组件网络请求（0.2.1 已实测）：验证代理设置生效；使用不返回响应的测试代理时，关闭窗口可及时取消等待中的请求并清理临时文件。
- 真实桌面：在 WebView2 中调用 Rust 命令，验证依赖定位、非法域名拒绝、目录配置读取及视频预览和封面加载。
- 真实下载：使用 `https://youtu.be/jNQXAC9IVRw`，完成 MKV 下载。FFprobe 确认文件包含 AV1 视频、Opus 音频，时长约 19 秒。
- 暂停续传：视频、音频各实际暂停一次，确认临时文件停止增长、下载子进程结束、参数锁定；继续后均输出 `Resuming download at byte` 并完成下载。合并／转换阶段暂停按钮禁用。
- 音频与字幕：FFprobe 确认 MP3 只含 MP3 音频；英语人工及自动字幕分别保存为 `.manual.en.srt` 和 `.auto.en.srt`，SRT 时间戳有效；视频＋字幕完成提示包含字幕文件。
- 单独字幕：移开测试字幕后重新下载，确认生成 SRT，媒体文件大小未变化；请求不存在的语言时返回明确错误，不生成字幕、不下载媒体。已有字幕文件也不能掩盖当前所选字幕缺失，单元测试覆盖此情况。
- 真实进度：收到可解析的百分比、下载速度和剩余时间事件。已修复 yt-dlp 缺失字段输出 `NA` 时产生无效 JSON 的问题。
- 画质和封装：选择 144p、MP4 后下载，FFprobe 确认有音视频流且视频高度为 144。
- 取消：任务取消后界面恢复可操作，未发现该桌面进程遗留的 yt-dlp、FFmpeg 或 Deno 下载子进程。
- 关闭窗口：解析期间关闭窗口，主进程退出，下载子进程被结束。
- 路径：真实下载目录包含中文、空格和 `&`，下载和保存正常。
- 正式版本：重新编译后启动原生窗口，确认未监听测试调试端口，并正常关闭。

原生自动化测试临时为测试版增加了本机调试端口，并使用独立应用标识隔离组件缓存，以便控制 WebView2。交付的正式版使用项目原配置重新编译，不包含这些测试配置覆盖。

## 未验证的范围

- 原生文件夹选择对话框未由自动化操作；已验证目录配置读取及指定目录实际写入。
- 未实测真实断网后的恢复和长时间下载；视频和音频的手动暂停续传已用真实下载验证，实际续传能力仍取决于源站与 yt-dlp。
- 只提取平台已有字幕，不做语音识别。源站返回的字幕列表可能随请求变化；所选字幕失效时会返回错误。合并、封装与转换期间不能暂停。
- 未测试登录、私有视频、地区限制、持续直播或其他操作系统；当前界面只提供无需登录的单视频下载。
- MP4 / MKV 使用原始编码，仅重新封装，不保证所有播放器均支持该视频的原始编码。
- 未做代码签名、安装器或程序本身的在线更新；设置中的更新入口针对下载组件。交付为 Windows x64 便携包，运行需要系统具备 WebView2。

## 本地复核命令

在源码包根目录、已配置 Tauri 开发环境的终端中执行：

```powershell
cargo test --manifest-path youtube-downloader/Cargo.toml
cargo clippy --manifest-path youtube-downloader/Cargo.toml --all-targets -- -D warnings
cargo fmt --manifest-path Handy-ytget/src-tauri/Cargo.toml -- --check
cargo test --manifest-path Handy-ytget/src-tauri/Cargo.toml
cargo clippy --manifest-path Handy-ytget/src-tauri/Cargo.toml --all-targets -- -D warnings
cargo build --release --manifest-path Handy-ytget/src-tauri/Cargo.toml --features tauri/custom-protocol
```
